# Contributing

1. Open an issue describing the user problem or browser behavior.
2. Fork the repository and create a focused branch.
3. Keep the local-first contract intact. Any network request, telemetry, storage change, or new permission must be explicit in the pull request.
4. Add or update tests for behavior changes.
5. Run `npm run check` before opening a pull request.

Do not claim universal browser support. Include the browser, version, operating system, recording format, and voice-follow availability in compatibility reports.
