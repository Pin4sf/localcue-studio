# Security policy

Report security or privacy issues through a private GitHub security advisory rather than a public issue. Include reproduction steps, browser and version, whether script or media data can be exposed, and a minimal proof of concept. Do not include another person's private recording or script.

Critical invariants:

- never upload scripts or recordings without an explicit feature and user action;
- never enable network-capable speech recognition under an on-device privacy claim;
- never label a format before checking what the browser produced;
- release a discarded take from application-controlled storage.
